Lunch Order — Admin

A private tool for the lunch rotation. It never changes GitHub by itself: it only prepares the two JSON files for you to download.

Load the data files

Choose current.json and history.json from the project's data folder. Select both files at once.

Alternative: open a terminal in the project folder, run python3 -m http.server, then open http://localhost:8000/admin.html.

Next steps

  1. Move the two downloaded files into the project's data folder and replace the old ones.
  2. Run these commands in the project folder: 
    git add .
git commit -m "Update lunch order"
git push
  3. Wait a minute or two. GitHub Pages then shows the new order to students.

Made a mistake? Reload this page. Nothing changes until you replace the files.
